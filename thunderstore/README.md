# W&W Inc. — Beta

Wizards & Witches Inc. is a spell-focused clan for Monster Train 2. An academy of wizards, witches, professors, and interns turns every fight into a questionable educational experience.

- **2 champions**, each with three upgrade paths.
- **43 cards:** 2 champions, 2 starting cards, 13 units, 22 spells, 2 equipment cards, and 2 rooms.
- **10 relics** and text in all ten game languages.
- **Arcane Slay:** rewards kills caused by spells.
- **Overheal:** uses healing that exceeds a unit's maximum health.
- Build around Conduit, spell upgrades, healing, and Wizard–Witch combinations.

This is a beta. Balance, translations, and some interactions are still being refined. Please include the card names, mod version, and your BepInEx log when reporting a problem.

## Installation

Install with Thunderstore Mod Manager or r2modman. Required dependencies are installed automatically: BepInExPack, Trainworks Reloaded **0.7.33 or later**, and Conductor **0.5.15 or later**.

If you have the local development build in `Local-WWInc`, disable or remove that copy before enabling this package. Keep only one installation of W&W Inc. active.

# W&W Inc. — Beta

Wizards & Witches Inc. es un clan de hechizos para Monster Train 2. Una academia de magos, brujas, profesores y becarios convierte cada combate en una experiencia educativa cuestionable.

- **2 campeones**, cada uno con tres sendas.
- **43 cartas:** 2 campeones, 2 cartas iniciales, 13 unidades, 22 hechizos, 2 equipos y 2 salas.
- **10 reliquias** y textos en los diez idiomas del juego.
- **Arcane Slay:** recompensa las bajas causadas por hechizos.
- **Sobrecuración:** utiliza la curación que excede la salud máxima de una unidad.
- Combina Conduit, mejoras de hechizos, curación y parejas de Mago y Bruja.

Es una beta. El equilibrio, las traducciones y algunas interacciones siguen en revisión. Para informar de un problema, incluye los nombres de las cartas, la versión del mod y el registro de BepInEx.

## Instalación

Instala con Thunderstore Mod Manager o r2modman. Las dependencias se instalan automáticamente: BepInExPack, Trainworks Reloaded **0.7.33 o posterior** y Conductor **0.5.15 o posterior**.

Si tienes la versión local de desarrollo en `Local-WWInc`, desactiva o retira esa copia antes de activar este paquete. Mantén una sola instalación de W&W Inc. activa.
